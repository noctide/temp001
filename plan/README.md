# plan · 工作计划与进度（架构维护）

| 路径 | 内容 |
| --- | --- |
| `wp/<编号>.md` | 工作包正本：目标、设计依据、图、接口、验收、允许路径、不做的事、分支名、依赖、预计大小、审核记录 |
| `STATUS.md` | `tl.py status` 生成：每个工作包状态、每个模块的规模与门禁结果、最近体检 |
| `CODEMAP.md` | `tl.py gen` 生成：每个模块 api 层对外函数一行说明 + 各登记表索引 |
| `archive/` | 早期启动指令等历史材料 |

流程见《开发项目划分与多Agent协作规范》5.4–5.6。
